# my-claude-tools

Claude Code まわりの自作ツールをまとめたリポジトリです。Mod（function hooks 型プラグイン）などを置いています。Claude Code 2.1.289 で動作を確認しています。

## 構成

ねこ部屋は、Mod（記録係）とビューア（表示係）の 2 つでできています。

```
 Claude Code（各タブ）                    ターミナル
┌─────────────────────────┐            ┌────────────────────┐
│ neko-agents（Mod）       │ rooms/     │ neko-room（ビューア）│
│ 猫の状態を作って書き出す │ ─────────▶ │ 読んで全画面に描く   │
└─────────────────────────┘  *.json    └────────────────────┘
```

| 名前                               | 種類   | 内容                                                                                                                   |
| ---------------------------------- | ------ | ---------------------------------------------------------------------------------------------------------------------- |
| [neko-agents](plugins/neko-agents) | Mod    | エージェントの動きを猫の状態にして、`~/.claude/neko-agents/rooms/<セッションid>.json` に書き出す。画面には何も描かない |
| [neko-room](tools/neko-room)       | ツール | 全タブの部屋のファイルを読んで、ねこ部屋をターミナルの全画面に描く                                                     |

## 使い方

```sh
# Mod を入れる（どの Claude Code でも猫が記録されるようになる）
claude plugin marketplace add Tora29/my-claude-tools
claude plugin install neko-agents@my-claude-tools

# ビューアを開く（ターミナルの別タブや分割した画面で。bun が必要）
bun ~/ghq/github.com/Tora29/my-claude-tools/tools/neko-room/room.ts

# よく使うなら alias に
alias neko='bun ~/ghq/github.com/Tora29/my-claude-tools/tools/neko-room/room.ts'
```

ビューアは `q` で終了し、図がはみ出したら `↑` `↓` `PgUp` `PgDn` かマウスのホイールでスクロールします。

## ねこ部屋の見方

```
── my-portfolio ──────────────────────────────────────────────────
                          ╭────────────────────────────╮
                          │ /\_/\  ボス           00:00│
                          │( -.- ) おやすみ中          │
                          │ (")(") 3 tools · 138k tok  │
                          ╰──────────────┬─────────────╯
                                         │
                         ┌───────────────┴─────=^.^=────┐
                         │                              │
          ╭──────────────┴─────────────╮ ╭──────────────┴─────────────╮
          │ /\_/\  ソラ           00:15│ │        ハチ           00:16│
          │( ^.^ ) ✓ 完了              │ │        留守 → ボス         │
          │ (")(") Explore · 8 tools   │ │ (___)  Explore · 8 tools   │
          ╰──────────────┬─────────────╯ ╰──────────────┬─────────────╯
                         ┆                              ┆
                         └┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┬┄┄┄┄┄┄┄┄┄┄┄┄┄┄┘
                                         ┆
                          ╭──────────────┴─────────────╮
                          │ /\_/\  クロ           00:05│
                          │( o.o ) ▶ Read types.ts     │
                          │ /| |\  general · 8 tools   │
                          ╰────────────────────────────╯
```

- 猫 1 匹（エージェント 1 つ）につき部屋（箱）が 1 つあります。メインのエージェントは親猫「ボス」（茶トラ）、サブエージェントは子猫です。
- Claude Code のタブ（セッション）ごとに「── プロジェクト名」の区画に分かれて、縦に並びます。
- **実線**は依頼の親子関係、**点線**は次のつながりです。点線でつながった猫は、つながり元の 1 段下に並びます。
  - **引き継ぎ**：前の子猫が完了した後に起動された子猫は、結果を受け取ったとみなす
  - **レビュー**：ほかの猫が書いたファイルを Read した
  - **お手紙**：SendMessage を送った
- 猫は線の上を歩いて、ほかの猫の部屋を行き来します（`=^.^=`）。
  - 起動した子猫は、親の部屋で依頼を受け取ってから自分の部屋へ帰ります。終わった子猫は、親の部屋へ報告に行きます。レビューやお手紙では、相手の部屋を訪ねます。
  - 出かけている間、自分の部屋は「留守」になり、訪ねた先の部屋には「+ミケ:報告」のように出ます。行きのセリフは歩く猫について動き、訪ねた部屋を出るときに消えます。
- 猫はときどきしゃべります（箱の 3 行目に 4 秒間）。起動したとき「いってくるニャ！」、ツールがエラーになったとき「あれ？おかしいニャ」のように状況に合ったことを言い、動いている間は 30 秒に 1 回くらいひとりごとを言います。長引くと「めんどくさいニャ…」とぼやき、子猫が働いている間に暇なボスは「ひまニャ…」と退屈します。
- 許可を待っている猫は、箱の枠が赤く点滅し、2 行目が「? Bash の許可待ち」になります。
- 子猫が終わると、結果を haiku で猫口調の 1 文に要約して報告します（例：「useAuth が重複してたニャ！」）。
- 子猫を使った作業が終わると、ボスがひと区切りの作業を 1 文にまとめてしゃべります（例：「useAuth の重複を見つけて直したニャ」）。ユーザーが入力してから、その作業の子猫が全員終わってボスが返事をしたときにまとめます。
- 最新の報告・まとめは図の下に出ます（「ソラの報告：…」「ボスのまとめ：…」）。
- 毛色は種類で決まります：Explore は白、Plan は三毛、general-purpose は黒、それ以外は id から決まります。
- ポーズで状態がわかります：running は手がパタパタ、idle は `( -.- )` の頭の上に zzz、完了は `( ^.^ )`、失敗は `( >.< )`、中断は空の箱です。
- 子猫が 6 匹を超えると、古い終わった猫から「帰宅した猫 ×N」として隠れます。

## 設定（`/config` の neko-agents）

| 設定                   | 最初の値 | 内容                                                                                          |
| ---------------------- | -------- | --------------------------------------------------------------------------------------------- |
| 結果を猫口調で要約する | オン     | 子猫が終わるたびと、子猫を使った作業が終わるたびに haiku で要約する（1 回あたり数百トークン） |

## 部屋のファイル

- 各タブは、猫に変化があったときだけ、多くても 0.5 秒に 1 回書き出します。働いている猫がいる間は、変化がなくても 1 分に 1 回書き直して、生きていることを示します。
- タブを閉じたときや `/clear` したときは「閉じた」と書きます。ビューアは、閉じたタブと 10 分以上更新のないタブを表示しません。
- 1 日以上たったファイルは、各タブの起動時に自動で消します。

## 開発

```sh
bun install

bun run check         # 下の全部をまとめて
bun run typecheck     # tools/ と plugins/*/ の型チェック（tsconfig.base.json が共通設定）
bun run lint          # ESLint
bun run format        # Prettier で整形（確認だけなら format:check）
bun run validate      # マーケットプレイスと全 Mod の claude plugin validate
bun run test          # bun test tools と、全 Mod の claude plugin test

# Mod をホットリロードしながら確認（保存すると自動で再読み込みされる）
claude --plugin-dir ./plugins/neko-agents
```

Mod の型チェックには、一度読み込んだときに `plugins/<mod>/.claude-plugin/types/` に生成される型定義を使います（生成物は `.gitignore` で除外しています）。各 Mod の `tsconfig.json` は、共通設定と生成された設定の両方を読み込みます。

リポジトリをローカルの marketplace として登録すると、フォルダが直接読み込まれます。編集後は `/reload-plugins` で反映されます。

```sh
claude plugin marketplace add ~/ghq/github.com/Tora29/my-claude-tools
claude plugin install neko-agents@my-claude-tools
```
